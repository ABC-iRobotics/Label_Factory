Table~\ref{tab:runtime} reports the wall-clock time of each stage over 20 scenes, measured on NVIDIA RTX 2000 Ada Generation Laptop GPU (8\,GB), 13th Gen Intel(R) Core(TM) i5-13600HX, 31\,GiB RAM. A scene takes 30.1\,$\pm$\,3.6\,min in total (mean $\pm$ std; 3 objects: 27.3\,$\pm$\,2.5\,min, 4 objects: 33.0\,$\pm$\,1.5\,min). The dominant stage is SAM-6D segmentation + pose estimation (59\% of the total). Keyframes were selected with a target overlap of 70\% for the reconstruction and 85\% for SAM-6D. All sequences contain 250 registered frames, while 45--78 frames (18--31\%) were selected for SAM-6D. The SAM-6D stage time grows linearly with the number of selected frames: 12.7\,s per frame for 3 objects ($r=0.97$, $n=10$); 19.3\,s per frame for 4 objects ($r=0.90$, $n=10$).
